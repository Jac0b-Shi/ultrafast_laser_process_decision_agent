# 流式对话与工艺分析验收及实验方案

## 功能边界

对话接口通过 POST SSE 返回真实模型文本片段、工具状态、目标和推荐结果。界面中的“执行过程”只对应已开始或已完成的服务端工具，不展示模型内部推理。工艺参数仍由历史案例或确定性推荐器产生，每组推荐必须附相似案例。

工艺分析使用独立参数组交叉验证比较仓库已有算法。RMSE、MAE 和 R² 是开发集选优指标，不作为独立测试成绩。评估生成账号隔离的不可变模型版本；启用、回滚和恢复自动选模均追加记录。反馈不会自动重训或替换模型。

## 统一任务集

1. 知识问答：比较飞秒和皮秒激光的加工机理。
2. 数据概况：列出可用材料和记录范围。
3. 缺失字段：仅提出“给 CFRP 推荐参数”，验证逐项追问。
4. 完整推荐：CFRP 深度 15 μm、容差 1 μm。
5. 多轮修改：在上一任务后输入“容差改成 0.5 μm”。
6. 推荐解释：询问上一组参数的案例依据和适用限制。
7. 无案例：选择无支持数据的材料或不可达目标。
8. 图片提取：从含明确材料、目标和单位的图片提取草稿。

每条任务固定账号数据快照、Provider、模型版本、提示和随机种子。图片和知识文件使用相同测试副本，不写入生产反馈。

## 对照与指标

- 同步完整响应与真实流式响应：首个可见状态时间、首段回答时间、总耗时、停止成功率、重试成功率。
- 本地规则与工具编排：任务完成率、目标字段准确率、工具选择准确率、无关推荐触发率、每轮工具次数和调用成本。
- 无知识检索与有知识检索：回答引用支持率、来源定位完整率和无依据陈述率。
- 工艺分析：分组隔离检查、候选覆盖率、评估失败原因、模型版本复现率和产物校验结果。

任务完成率与工具选择由预先标注的期望结果判断。时间从浏览器发送请求开始采集；成本使用服务端结算记录。主观易用性需要另行开展真实用户试验，本方案不预填用户体验结论。

## 验收清单

- OpenAI-compatible 与 Ollama 均逐段到达浏览器，代理不缓冲，15 秒心跳维持连接。
- 断线、停止、Provider 失败及服务重启均留下明确状态；失败调用释放预留额度。
- 相同请求标识只能对应同一输入，重放不新增对话、推荐或费用。
- 长对话只向模型发送最近 12 组历史消息，同时保留当前结构化目标并提示截断。
- 每账号默认一个评估任务、全局默认一个 worker 槽；环境变量可将上限调整到 1–4。
- 版本文件位于运行时目录并校验 SHA-256；跨账号读取和启用返回 404。
- 新反馈保存当时的预测、模型版本和来源；旧反馈显示缺失，不事后补算。
- 桌面与手机验证中文输入法、Shift+Enter、停止、草稿保留、向上阅读停止跟随和“回到最新”。
