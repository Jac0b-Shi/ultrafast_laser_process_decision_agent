# 产品验收记录

本机仅为开发验收环境。正式环境是 server-shu；功能分支经 PR 审阅后才合入 main，部署方式见 [管理与部署](admin-credit-deployment.md)。

## 已验证功能

- 登录与管理员建号、角色/启停管理、邮箱与头像回退、密码变更撤销会话、初始入口自动启停。
- 公共记录只读共享；会话、推荐、反馈与知识上传下载按账号隔离。
- 历史优先单组推荐、设备约束与支持域检查、14 类预测算法、确定性中间量与公式审核。
- 反馈追加、修正留存旧版本、删除后退出计算、30 天恢复边界及无主反馈认领。
- 网页 LLM 配置与加密密钥、三类 token 成本/售价、价格快照、原子预留、幂等结算、透支边界、失败免扣和未知用量处理。
- 人工充值/赠送、多用户限次激活码、钱包明细和管理员成本 CSV。

## 验证方法

Docker 产品后端测试覆盖以上权限、迁移、计费及并发边界。浏览器隔离验收覆盖初始入口切换、网页建号、额度、模型连接测试、激活码下载/核销、付费解析、免费历史推荐、账单隔离及停用会话失效。模型调用使用本地 SSE fixture，无真实供应商费用。

`qa_llm_fixture.py`、`browser_credit_smoke.cjs` 属于产品验收；`backup_agent.py` 用于运行数据、密钥与知识文件配套备份。运行数据与测试产物不提交。
# 对话式 v1.0 验收补充

- 页面名称为“超快激光加工工艺数据库智能体系统”，产品版本显示 `v1.0`；名称前无烧瓶／数据库标志。
- 普通问题无需预先填写工艺表单；`Enter` 发送、`Shift+Enter` 换行，中文输入法组合输入不触发提前发送。
- 推荐要求材料、质量目标、容差均明确。缺失字段时返回追问；参数与案例依据只来自服务端确定性推荐器。
- 重新打开历史任务后，用户消息、助手回答、工具事件和推荐引用均可查看。
# 流式与分析增量验收

流式事件、模型版本和论文实验指标的详细清单见 [streaming-analysis-experiment.md](streaming-analysis-experiment.md)。生产构建需同时包含 `api`、`web` 和 `worker`，反向代理必须保留 `text/event-stream` 并接受 `X-Accel-Buffering: no`。

部署脚本在拉取新镜像前，将当前 API 与 Web 镜像保留为 `rollback` 和带上一提交号的本地标签，并把已部署提交写入持久状态目录；镜像清理不得删除这些标签。
