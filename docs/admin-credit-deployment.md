# 管理员、模型和 Credit 运维

正式环境是 `server-shu`，监听 Gitee `main` 自动更新。本次改动先在 `feat/agent-admin-credit-journal` 审阅，合并前不部署到服务器。本机 Docker 仅用于开发验收。

## 首次更新

服务端 `.env` 至少保留端口和 `LASER_ADMIN_USERNAME`、`LASER_ADMIN_PASSWORD`（12–256 字符）。HTTPS 入口设置 `LASER_COOKIE_SECURE=true`。模型地址、API Key 和价格迁入数据库；首次访问模型目录时兼容导入旧 `providers.yaml` 与其指定的密钥环境变量，完成导入后再删除旧环境配置。

SQLite 迁移使用 `PRAGMA user_version=2`，修改旧库前自动写入 `experiments/agent/backups/before-v2-*.sqlite3`。账号 ID、会话归属和追加反馈事件保留。初始账号与普通管理员分开：存在启用的普通管理员时，初始账号停用并撤销其会话；没有时恢复初始入口。初始账号的数据不转移。网页停用账号、重置密码或修改角色会撤销其会话。

首次登录后，在管理中心创建带邮箱的普通管理员，再以新管理员登录。旧账号可暂缺邮箱，个人资料页提示补全。头像使用规范化邮箱的 SHA-256 Gravatar 地址，加载失败退回首字母头像。

## 模型与计费

大语言模型与加工预测算法分别管理。管理员设置协议、地址、模型、输入/输出上限、超时、启停、可见性、默认项，以及缓存输入、未缓存输入、输出三类成本价和独立售价，单位为 RMB/百万 token。每次保存保留价格版本；账单记录调用时价格快照。API Key 仅允许替换或清除，不回显。

固定 1 RMB = 100 credit，账本使用整数微 credit。新账号余额和信用额度为零，管理员可充值或赠送，亦可生成多人限次激活码。余额、信用额度与已有预留共同限制付费请求；已欠费或已有透支预留时不再接受新的付费调用。输入按字节保守上界预留，输出按可用额度收紧；上游超预算时关闭流，用户欠费不超信用额度。

只有成功的 AI 操作按可靠实际用量结算。失败、输出中断、非法解析结果不扣用户费用，已知供应商成本仍记录；未知用量标记待核对，不估算扣费。管理员连通性测试与公共关系提案是平台用途，日常用户对话照常计费。免费历史复用与本地计算不调用外部模型。

钱包提供独立操作明细与追加流水；管理中心按时间、账号、模型、用途查询成本并导出 CSV。人工充值、赠送和激活码到账分别统计，不算已消费收入。请求标识保证结算和核销幂等。中断后超过 15 分钟的未完成预留，在下次钱包查询或模型调用时自动释放，保留异常记录供核对。

## 备份与恢复

模型主密钥位于 `experiments/agent/secrets/model.key`，自动生成并持久化，不能只备份数据库。运行：

```powershell
docker compose run --rm --no-deps -e PYTHONPATH=/service -v "${PWD}/scripts:/workspace/scripts:ro" api python /workspace/scripts/backup_agent.py
```

快照同时包含 SQLite、密钥、知识文件和文件哈希清单。恢复时先停止本项目 API，再从同一快照恢复 `state.sqlite3`、`secrets`、`blobs`，不要混用不同实例的主密钥。模型已有加密数据但密钥文件丢失时明确报错，不生成替代密钥。运行库、密钥、上传与导出产物排除于 Git 和 Docker 构建上下文。

`data/raw` 原始数据及公共文献文件沿用服务器既有持久化目录。本 PR 不包含本机私有账号、用户上传、反馈和钱包数据；若服务器尚无文献，管理员须部署既有授权文献到 `docs/literature` 再导入。
